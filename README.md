# Marvel API Project

This project is part of my learning journey in PHP. It makes a call to an API and returns data about the upcoming Marvel movie.

## Live Project

You can check out the live project [here](https://next-marvel-movie-class.vercel.app/).

## Why is the project in the "api" folder?

You might be wondering why the entire project is located in an `api` folder. Well, that's because of [Vercel](https://vercel.com/) 🙃. They require this structure to deploy the project correctly.
